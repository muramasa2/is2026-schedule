# Interspeech 2026 聴講スケジュール Web アプリ

ICC Sydney（2026/9/28–10/1）の個人聴講行程を、スマホと PC の両方で確認・更新するための静的 Web アプリ。
サーバー・ログイン・ビルド不要。`schedule_data.json` を差し替えれば別会議にも使える。

## 起動

```bash
cd is2026-schedule
python3 -m http.server 8173
# → http://localhost:8173
```

`npx serve` や GitHub Pages / Netlify などの静的ホスティングでも動く。
スマホで使うときは同じ Wi-Fi の PC の IP（例 `http://192.168.x.x:8173`）を開き、ブラウザの「ホーム画面に追加」で PWA として入れると機内モードでも開ける（Service Worker が全アセットとデータをキャッシュ）。

`index.html` をファイルとして直接開いた場合（`file://`）は `schedule_data.js` がフォールバックとして読まれる。
JSON を更新したら次を実行して JS 版も同期する：

```bash
python3 build_data.py
```

## 画面

| 画面 | 内容 |
|---|---|
| Today | 日タブ（起動時はシドニー時刻の「今日」）。進行中の枠をハイライト、上部に「次の枠まであと N 分」を固定表示。会場名はタップでコピー |
| All papers | 全発表 85 件の一覧。タイトル・著者・番号・会場で検索、S/A/B・口頭/ポスター/特別・聴いた/★/メモありで絞り込み。タップで該当日の位置へジャンプ（別案の中にある発表も展開して表示） |
| Read later | `readingList`（自分の発表・座長と重複するもの等）。メモ・チェック可 |
| Settings | JSON エクスポート／インポート（PC⇄スマホ同期）、Markdown 書き出し、テーマ、固定予定、未確認事項、時刻シミュレーション、キャッシュ更新 |

### 候補の選択（choice 枠）
- 枠上部のセグメントで選択肢を切替。選んだ案の中身だけが展開され、他は「別案：…」に折りたたむ（タップで中身と理由を確認できる）。
- 「候補を比較して選ぶ」で、全候補の発表（優先度・著者・日本語の概要／選定理由・失うもの）を並べて比較してから選べる。
- 選択は `localStorage` に保存され、再読み込み後も維持。火曜午後は `14:00 に C3.4 で確認` の注意文を表示。

### メモ・チェック
- 各発表の「メモ」でテキスト欄が開き、自動保存。`paperNo`（無ければ `code`、それも無ければ slot id）をキーにするので、同じ論文（例 #1111）は複数日で同じメモを共有。
- 「聴いた」「☆ 後で読む」のトグル。`questions` に用意した質問はメモ欄の上に表示。
- Settings →「Markdown をダウンロード」で、日付順にタイトル・番号・会場・チェック状態・質問・メモを Markdown 化。「メモ・チェックのある発表だけ」のオプションあり。

### 時刻
- すべて `Australia/Sydney`（`Intl.DateTimeFormat` の `timeZone`）で判定。端末が日本時間でも正しく「進行中」になる。
- テスト用に `?now=2026-09-29T14:05`（シドニー時刻）で現在時刻を仮設定できる。Settings からも設定可（タブ内のみ）。

## ファイル
- `index.html` / `styles.css` / `app.js` — アプリ本体（依存ライブラリなし）
- `schedule_data.json` — データ（表示ロジックと分離）。`schedule_data.js` はその自動生成フォールバック
- `sw.js` / `manifest.webmanifest` / `icon-*.png` — PWA（オンライン時はネットワーク優先、オフライン時はキャッシュ）
- 保存キー: `localStorage["is2026:state"]`（`schemaVersion: 1`）
